Install guide

Install the Video Editor agent

One skill, video-editor, turns Claude Code, Codex or OpenCode into an editor that cuts footage with FFmpeg and builds motion graphics with Hyperframes and GSAP. Pick an install path, then the agent learns your brand and connects Google Drive.

  • FFmpeg 5+
  • Node.js 24+
  • Python 3.10+
  • Chromium / Chrome
  • rclone 1.60+
  • Git + curl
Step 1 · Choose a path

Three ways to install

All three end the same way: the agent asks about your brand, saves it to brand/profile.md and asks for any missing connection.

ARecommended

Ask your agent

Open your agent in the folder where the video work will live and send this message.

Install this: https://github.com/orage-developers/skills-editor

Codex only copies the skill. It finishes setup on your next video message, for example "I want to make a reel for my brand".

B

Clone and run the scripts

Full control. Each agent instance is its own copy with its own brand and memory.

git clone https://github.com/orage-developers/skills-editor.git my-video-agent
cd my-video-agent
bash video-editor/scripts/setup.sh
bash video-editor/scripts/doctor.sh
bash video-editor/scripts/install.sh --dry-run
bash video-editor/scripts/install.sh

Then start claude, codex or opencode in that folder and say hi.

C

Skills manager

Installs only the skill folder, for this project or for every project.

npx skills add orage-developers/skills-editor --skill video-editor
# or, for every project:
npx skills add orage-developers/skills-editor --skill video-editor --global

Then run <skill folder>/scripts/setup.sh from the project root, or tell your agent "set up the video editor".

Step 2 · First session

What happens after install

On the first message of every session, the agent runs these steps before any editing. You answer questions; it runs the commands.

  1. Prepare the workspace

    setup.sh writes AGENTS.md and CLAUDE.md, creates brand/, memory/ and jobs/, and links the skill for each tool. Each session starts with:

    python3 video-editor/scripts/workspace.py init
bash video-editor/scripts/doctor.sh

  2. Brand interview

    Four short rounds: identity, look (logo, hex colors, fonts), voice and video style, references and rules. Answer "skip" to anything; the field is saved as TBD. Share a website or brand guide and the agent samples what it can. It reads back a summary for you to confirm.

  3. Connect Google Drive

    Finals are delivered through an rclone remote named gdrive. Run the login in your own terminal; it opens a browser for Google sign-in.

    rclone config create gdrive drive scope=drive
rclone lsd gdrive: --max-depth 1   # verify

    Headless server: run rclone authorize "drive" on a computer with a browser, then paste the token into rclone config on the server.

  4. Install missing tools

    If the doctor reports a FAIL, the agent shows the dry run and asks before installing anything. install.sh uses apt, dnf, pacman, zypper or Homebrew, installs Chromium through Playwright, the Hyperframes CLI, the reel Python venv and the matting model.

    bash video-editor/scripts/install.sh --dry-run
bash video-editor/scripts/install.sh                # everything
bash video-editor/scripts/install.sh --skip-system  # no sudo, no package manager
bash video-editor/scripts/install.sh --skip-reel    # skip the reel venv

  5. Save state

    The agent records the doctor result, brand status and connections in memory/index.md. Next session it skips straight to your request when everything is ok.

Troubleshooting

Common fixes

Broken reel venv

reel-venv/bin/python: No such file or directory, or transcription and matting fail. An API key does not fix this. Recreate the venv:

bash video-editor/scripts/install.sh --skip-system

PyAV too new

TypeError: open() got an unexpected keyword argument 'metadata_errors'. Only the doctor's decode test catches it. install.sh pins av<18; run it again.

sudo asks for a password

The agent can't type it. Run the command it gives you yourself. In Claude Code, type ! <command> so the output lands in the chat.

Node.js missing

install.sh does not install Node. Install version 24, then rerun the script.

nvm install 24

Windows

Use WSL2 with Ubuntu and run everything inside it.

Containers and CI

Install system packages in the image, then run install.sh --skip-system.
